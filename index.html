The systems index

The case studies are the deep dives. This is the wider shelf, and every item on it runs today.

Layout as CI Pigasus
A postbuild gate lays every built page out in headless Chrome and fails the deploy if any block sits more than 4px off its axis. Its first run found 669 defects that code review had passed.
Design-token linter Pigasus
Bans raw color utilities after a real incident where near-black ink rendered invisible in dark mode and one visitor's tap broke a tool permanently.
Right Ray / Wrong Ray davessweater.com
Public monthly report cards scoring real weather forecasters on a 100-point rubric, with tolerance bands, a wind vagueness tax, and dated recalibrations in the code.
Public forecast API + widget davessweater.com
CC BY 4.0 consensus forecast where every response carries its license and attribution, and the embeddable widget loads zero analytics because it runs on other people's pages.
Function-budget CI gate davessweater.com
Born from a ten-day silent production outage where builds failed after "Build Completed." Every PR now gets a fast static model plus a ground-truth build, and the postmortem records which fixes were measured and dropped.
Copy-lint shared infrastructure
Lints the shipped artifact, meaning JSX text nodes, metadata, and aria-labels, where draft-stage validators can't look. Found 156 violations in a tree that had passed months of human review.
The writing styleguide layer shared infrastructure
A machine-enforced house styleguide with tiered AI-tell rules and a quarterly re-check cadence, because surface tells decay with every model generation. This site's copy was written under it.
Citation standard shared infrastructure
An evidence-grading ladder written after one unsourced intake line propagated into sixteen assertions across nine documents.
Evidence-review gate Pigasus
Every audit finding gets a confidence rung, hypotheses are barred from action items, and the review pipeline stops before synthesis when the gate fails.
Anonymous benchmarks with a floor Pigasus
Calculator benchmarks enforce a 25-run minimum per segment cut, because in a small market "median ticket, one town, one vertical, n=3" is three identifiable businesses.
Freshness-gated artifact pipeline Corpay methodology
Every analysis stage writes a dated artifact and downstream stages read artifacts instead of re-pulling, so a "full" audit is usually a partial re-pull and every number traces to the run that produced it. Written up so another team could rebuild it from scratch.
Multi-agent orchestration cross-project
Chartered orchestrator sessions dispatch work through self-contained briefs, with a model-cost ladder as policy and the failure mode named in the charter itself.
Busy-ness Index davessweater.com
A 14-day tourism-demand model whose code documents its own known v0 bias, and whose outputs stay flagged provisional until enough history exists to earn a baseline.
Synthetic research, gated Pigasus
Persona-elicited text embedded and projected onto anchor statements instead of asking a model for a rating, hard-gated on replicating a real study before any deployment.
