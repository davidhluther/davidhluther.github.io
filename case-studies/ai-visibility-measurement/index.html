AEO measurement · Pigasus Group + Corpay methodology

Measuring AI visibility without fooling yourself

Anyone can paste a prompt into ChatGPT and screenshot the answer. Building an instrument you can defend in front of a CMO is a different job. This is how I do it, twice: once as a solo-built system I own end to end, and once at Fortune 1000 scale.

The Pigasus battery: a frozen instrument

For my consultancy I built an AI-visibility instrument around a frozen 28-prompt battery run monthly against ChatGPT, Claude, Perplexity, and Gemini: 112 answer cells per month. The prompts are organized into six groups that mirror how buyers actually approach a category:

  • Local discovery: "is there anyone near me who does X" queries, typos deliberately left in, because the typos are what make a prompt read as a person rather than a search marketer.
  • Problem-first: symptoms described with no category vocabulary at all, where getting cited matters more than getting named.
  • Category education: what the category does and costs, before any brand enters the conversation.
  • Continuity and AI-enablement: the forward-looking questions a category's buyers are starting to ask.
  • Brand and verification: direct brand lookups, scored as disambiguation tests and deliberately excluded from the headline number, because naming a brand you just typed proves nothing.
  • Controls: three deliberately unwinnable prompts kept as a baseline tripwire for geo-inference and category literacy.

Prompt IDs are frozen forever once published. Prompts are never edited, only retired in place with a note, so the time series stays comparable month over month. The screening that got from 62 candidate prompts down to 28 is preserved in an appendix, cut by cut, for auditability.

Protocol before tooling

The battery of record is run by hand in the consumer apps: one prompt per fresh chat, logged out or on a clean profile, memory and personalization off, no VPN, from the business's home geography, same day each month. Answers are pasted verbatim before scoring, on the principle that your summary of the answer is not the instrument; the answer is. Each run records the model version string, because a silent default-model swap can move a score without anything about the business changing.

What gets scored per cell: whether the business was named unprompted, at what position, which domains were actually cited (distinct from businesses merely name-dropped), and every competitor offered as an answer. Misses are classified by type: visibility gap, category-belief gap, or resolved-to-the-wrong-kind-of-answer.

The API runner and its refusal conditions

A Python runner queries the four vendor APIs directly as a supplementary track, filed under a separate tag so API-collected answers can never contaminate the consumer-UI series (the two are different instruments: the API has no browsing layer, no memory, no consumer geo-inference). The runner refuses to run against an unfrozen prompt set, and refuses to spend money on any provider whose model ID hasn't been human-verified against live docs:

class Provider:
    name: str            # short tag used in the raw filename (<name>-api)
    env_keys: list[str]  # env var(s) that hold the API key (first hit wins)
    model: str           # the model id the adapter targets
    verified: bool       # False => refuse live calls until confirmed vs docs
    docs_url: str        # where to confirm endpoint + model id
    verify_note: str     # what to check before flipping `verified` to True

Downstream, a 17-module analysis suite covers mention and share-of-voice math, citation verification (assistants fabricate links; every cited URL gets checked), sentiment and factual-error review, competitive and per-platform variance analysis, and trend reads with confound checks for model-version swaps. A dedicated evidence-review gate assigns every finding a confidence level and blocks synthesis until claims pass. Client separation is architectural: every module is parameterized by an engagement slug, so the same logic runs unmodified across engagements and no client data lives in code.

The same discipline at Fortune 1000 scale

At Corpay I own AI visibility as a growth channel for a corporate payments platform. The numbers stay internal; the methodology travels, and the methodology is the interesting part.

Prompt-pool noise correction

AI-visibility platforms blend prompts a human curated with a much larger machine-generated pool inferred from a short niche description. The generated pool drifts toward raw search demand, which for a B2B finance brand means consumer personal-finance questions the brand's buyers never ask. Every metric built on that denominator is diluted, and the dilution masquerades as a finding ("we're invisible in AI") rather than what it is: a measurement artifact.

The correction treats pool composition as a named dimension of every metric, with composable filters: restrict to the curated corpus, exclude branded prompts (being mentioned in an answer to "what does [brand] do" proves nothing), and strip off-ICP prompts with a classifier whose blocklist was derived empirically, from watching which off-market companies surfaced as "competitors" in the diluted report. Two rules carry the weight: nothing is replaced (the original series keeps running unchanged, and cleaned figures publish alongside it under a separate key), and every figure must name its pool inline. An unlabeled metric is not citable. The flattering number and the unflattering one ship side by side, because they answer different questions.

AI-traffic forensics

"How much traffic comes from AI assistants" looks like a lookup and is actually a definitional minefield. Enterprise and free analytics stacks disagree materially on the same pages in the same month, because each ships its own undocumented rules for what counts as an AI referrer; a single export can contradict itself across two report paths. The forensic posture: triangulate rather than trust. Build named-referrer cuts by hand so the inclusion list is inspectable, state every metric with its full construction (which referrers, which window, which report path, pulled when), reconcile the platforms side by side and name each definitional gap rather than forcing agreement, and trace circulating legacy figures back to a live report path or record them as unreproducible. "Unverifiable" is a valid, publishable outcome.

The pitfalls are worth more than the totals: every AI-traffic number is a floor (assistants that strip referrers land in Direct, and no configuration fixes it); AI Overviews clicks arrive as ordinary organic and are invisible to referrer cuts entirely; and paid-channel misclassification can silently invert a whole narrative between platforms. I proved that last one at Corpay with a controlled experiment rather than an assumption.

Reporting you can't fake

The measurement program runs on a CI/CD pipeline with hard separation between the data layer and the synthesis layer. Scheduled jobs pull vendor APIs and commit raw responses to a cache; narrative generation runs strictly from cache, where zero API spend is guaranteed by the absence of a network session, not by a flag. The LLM that drafts executive narrative is treated as an untrusted component: its model choice was settled by an A/B test in which the cheaper model fabricated a number, and every generated figure passes a mechanical grounding check against source data before anything publishes. A run that fails a gate publishes nothing; a run that concludes "blocked" publishes the verdict, because that's a valid result. The companion job that watches CMS publishing authenticates with a read-only delivery credential, so it is structurally incapable of publishing: humans publish, automation notices.

The through-line

Every number carries its provenance: source, window, pull time, and which pool or basis produced it. A figure without that lineage doesn't get cited in a deliverable, no matter how good it looks. AI visibility is a new channel with immature tooling and enormous appetite for headline numbers, which makes measurement honesty the whole game.

The instrument you can defend beats the number you wish were true.
